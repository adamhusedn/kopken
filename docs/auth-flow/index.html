Alur Register & Login

Penjelasan visual alur autentikasi aplikasi Kopi Kenangan (Satu Kenangan), hasil analisis file bundle front-end.

Kesimpulan utama: Tidak ada endpoint register terpisah.

Register & login digabung dalam satu alur "Login via WhatsApp" berbasis reverse OTP. Identitas diverifikasi dari nomor pengirim WhatsApp, bukan dari kode yang Anda ketik. Jika nomor belum terdaftar, mengirim pesan pertama otomatis membuatkan akun — itulah "register"-nya.

3 Endpoint & Body

Fungsi API yang terlibat beserta struktur body-nya.

LangkahFungsiEndpointBody
Mulai OTP (login/register) whatsapp_reply_otp POST /web_order/api/satu_kenangan/whatsapp_reply_otp { device_id, device_type, otp_type: 1004 }
Cek status OTP (opsional) whatsapp_otp_status POST /web_order/api/satu_kenangan/query_whatsapp_reply_otp_status { serial_num }
Alternatif berbasis nomor* get_access_token POST /web_order/api/satu_kenangan/get_access_token { phone }

* get_access_token tidak dipakai pada alur Landing utama; alur utamanya murni reverse-OTP lewat whatsapp_reply_otp.

Respons whatsapp_reply_otp saat sukses:

{
  "error_code": 0,
  "data": {
    "serial_num": "...",
    "reply_to_phone": "62xxxxxxxxxx",
    "whatsapp_content": "teks berisi kode unik yang harus dikirim",
    "account_error": null
  }
}

4 Header Standar

Fungsi post() menambahkan header ini ke setiap request.

Accept: application/json
language: id            (dari localStorage, default "id")
time_zone: <offset jam> (mis. 7 untuk WIB)
authorization: <token>  (jika sudah login)

5 Cara Pakai (Nomor Sendiri)

  1. Buka https://order.kopikenangan.com/sk/ di HP yang ada WhatsApp-nya.
  2. Klik tombol "Login via WhatsApp".
  3. WhatsApp terbuka dengan pesan sudah terisi — kirim apa adanya ke nomor resmi.
  4. Kembali ke browser, klik "Refresh".
  5. Masuk ke Home. Jika nomor belum terdaftar, akun dibuat otomatis di langkah ini.

Karena verifikasi memakai nomor pengirim WhatsApp, gunakan HP & nomor Anda sendiri.

6 Catatan Teknis

  • Reverse OTP: Anda mengirim pesan berisi kode (bukan menerima lalu mengetik). Server verifikasi dari nomor pengirim.
  • otp_type: 1004 = kode jenis OTP untuk alur login WhatsApp ini.
  • device_id dibuat sekali lalu disimpan di localStorage["sk:deviceId"], digunakan ulang berikutnya.
  • share = objek berisi nama key localStorage (share.token, share.language, share.serial_num), didefinisikan di bundle inti Vue.
